# trysolti/.github

Repository powering the [trysolti organization](https://github.com/trysolti)
profile page on GitHub:

- `profile/README.md` — the organization profile README rendered on the org
  overview page.
- `profile/assets/` — brand assets shared with the profile README (logo variants and
  the organization avatar), sourced from `solti-landing/public/images/`.

The organization avatar itself is uploaded through the GitHub UI
(Settings → Organization profile); `assets/solti-avatar.png` is the source
file (1024×1024, S symbol on the splash dark background `#1e1e1e`).

> Managed as part of **Change 043** in the `solti-specs` repository.
