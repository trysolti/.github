<h3 align="center">Batch processing simplified, at the lowest cost.</h3>

<p align="center">
  Solti is a platform for scheduling asynchronous jobs — from simple tasks like
  sending emails to complex workloads like data processing and ML model
  training — without provisioning or managing any scheduling infrastructure.
  Write your task, submit it declaratively, and Solti routes each job to the
  most efficient provider at submission time.
</p>

<h3>Get started</h3>

Install the CLI with Homebrew, then run `solti account login`:

```bash
brew install trysolti/tap/solti
```

Prefer an AI agent to do it for you? Grab the quickstart skill from
[`trysolti/skills`](https://github.com/trysolti/skills) and hand it to your
agent — it handles CLI bootstrap, login, and workspace setup in one prompt.
